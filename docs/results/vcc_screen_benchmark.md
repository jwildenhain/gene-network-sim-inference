# Virtual Cell screen benchmark

290 simulations in 29 settings, every algorithm on the same noisy cells (40 cells per perturbation, calibrated networks, measurement artefacts). Score: AUPR for the true direct edges over the perturbed genes. Generated by `scripts/run_vcc_benchmark.py --report`; the studio's Virtual Cell tab shows the same numbers with filters.

Verdict marks: ✓ beats the random ranking *and* the hubness-only control (paired Wilcoxon, BH-corrected, q < 0.05, lift ≥ 1.5); ~ beats random but not the hubness-only control (ranks hub genes, not pairs); ✗ not better than random (not appropriate); ✗✗ worse than random; · control.
