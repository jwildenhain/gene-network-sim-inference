Columns: *F1*, *recall*, *precision*: mean over runs at the algorithm's own edge count (± SD for F1); *AUPR*: mean over the runs that stored it (rescored runs may lack it); *errors*: mean total errors; *median s*: median run time of the algorithm on one network. Controls (`by_chance`, `gene_features`) are listed last. Runs differ in topology, noise, perturbation model and parameters; they are pooled within a size group, so the SD mixes network and seed variation. Rows were stored over several days of code changes (the archive keeps no code version per row).
