                ⚙️ Usage Modes in phpIoRN & Parameter Estimation
              

              

                

                  ⚡ Direct Empirical Mode (Wrangled Real Data):
                  

                    Algorithms consume the raw expression matrix X and perturbation matrix U directly to solve A*X = -U or regressions without numerical ODE simulation.
                  

                

                

                  🔬 Biophysical Parameter Estimation Mode:
                  

                    Real steady states estimate basal synthesis v_i = b_i*x_ctrl, degradation b_i=1.0, and Hill threshold affinities K_ij = median(|X_j|)+0.1. The non-linear Hill ODE solver then integrates dynamic trajectories x(t).
